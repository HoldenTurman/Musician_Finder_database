# Musician Finder Database

Musician Finder is a database project designed to connect musicians, bands, vendors, and event organizers.

## What It Does

The database allows musicians to create profiles containing information such as:

- Instruments they play
- Experience and skill level
- Musical interests and preferences
- Availability and other relevant profile details

Musicians can use this information to discover people to play with, form groups, and join bands.

The project also supports a commercial side of the music community. Vendors and event organizers can find musicians for performances and events, while musicians can discover paid opportunities and connect with vendors who need entertainment.

## Project Contents

- `01_schema.sql` — Creates the database tables and relationships
- `02_seed.sql` — Inserts sample data
- `03_queries.sql` — Contains example queries for working with the database
- `PersonalProjectERD.png` — Entity relationship diagram
- `*.mwb` — MySQL Workbench project files

## Purpose

The goal of this project is to provide a central platform for building musical connections, forming bands, and connecting musicians with performance opportunities and music-related businesses.
